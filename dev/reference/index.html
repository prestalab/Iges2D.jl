Iges2D.CircularArc — Type
CircularArc(center, start, stop; ccw = true)
CircularArc(center, radius, start_angle, stop_angle; ccw = true)

Circular arc in the z = 0 plane (IGES entity 100). Angles are radians. Equal endpoints or angles differing by whole turns denote a full circle. Small nonzero arcs remain arcs. ccw=false walks clockwise from start to stop; entity 100 preserves the locus by swapping the endpoints on export.

Iges2D.NurbsCurve — Type
NurbsCurve(degree, knots, points, weights)
NurbsCurve(degree, knots, points)

Rational B-spline curve (IGES entity 126). knots must hold length(points) + degree + 1 non-decreasing values, weights are strictly positive, and interior knots may not repeat more than degree times. The parameter range is [knots[degree+1], knots[end-degree]].

Iges2D.as_nurbs — Function
as_nurbs(arc::CircularArc; max_piece = π/2)

Exact rational-quadratic NURBS representation of arc. Each piece is a rational Bézier with weights 1, cos(Δ/2), 1, so the sweep Δ of one piece must stay below π to keep the middle weight positive. The arc is split into ceil(sweep / max_piece) pieces joined at the arc's own junction points by double knots; a full circle becomes four pieces with weights 1, √2/2, ....

source
Iges2D.fit_nurbs — Function
fit_nurbs(points::AbstractVector{Point2}; degree=3)

Global B-spline interpolation (Piegl & Tiller, The NURBS Book, Algorithm A9.1) through points (at least degree + 1). Parameters are chord-length, the knot vector is built by averaging, and the linear system is solved directly (normal equations square the condition number and destabilise the fit). Returns a NurbsCurve with length(points) control points that passes through every sample within round-off.

source
Iges2D.normalized — Function
normalized(curve::NurbsCurve)

Affinely rescale the active parameter interval to [0, 1]. Control points and weights are unchanged. Normalization is optional; export preserves the domain.

IGES files

Iges2D.IGESFile — Type
IGESFile(path=nothing; units=:mm, product="Iges2D.jl", native=product,
         receiver="", preprocessor="Iges2D.jl <version>", author="",
         organization="", date=nothing, model_date=nothing)

A collection of planar curves. Metadata and the exported basename must be printable ASCII; punctuation and whitespace are preserved in Hollerith strings. Timestamps are YYYYMMDD.HHMMSS; omitted dates use UTC.
